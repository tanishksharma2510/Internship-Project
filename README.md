# What the project does ?
This project applies supervised machine learning to the problem of tour and hotel booking cancellations, using a large, real-world hotel bookings dataset as a proxy for the broader tourism and hospitality booking ecosystem. By learning the patterns that precede a cancellation — such as deposit type, lead time, booking channel, and a guest's past cancellation history — the system aims to flag high-risk bookings at the time of reservation, giving revenue managers time to act before the booking is lost. The end product is not merely a predictive model but a complete decision-support workflow: data acquisition, cleaning, exploratory analysis, feature selection, model comparison, and deployment as an interactive dashboard that a non-technical revenue manager can use directly.

# Why the project is useful ?
This project is useful in various ways for the hospitality industry. Some of the key benefits of this project are as follows: -
1) Develop an accurate, user-friendly, and interactive prediction system.
2) Assist hotels and travel businesses in making better data-driven decisions.
3) To enhance operational efficiency, optimize resource planning, and contribute to effective revenue protection strategies.
4) It also helps organizations to improve their booking management.

# How users can get started with the project ?
1) Clone this repository.
2) Install the required Python libraries, i.e., pandas, numpy, plotly (both express and graph_objs), sklearn, pycountry, and xgboost.
3) Run the main Dash application file (e.g., app.py).
4) Open the local server URL in your web browser to access the application.
